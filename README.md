# Hibbullah Landing Page

A responsive, static product landing page for the Hibbullah pharmacy app.

## Stack

- Semantic HTML
- Vanilla CSS
- Vanilla JavaScript
- Google Fonts: Sora and Plus Jakarta Sans
- No framework, build tool, or runtime dependency

## Run locally

Open `index.html` directly, or serve this directory:

```bash
python3 -m http.server 4173
```

Then visit <http://localhost:4173>.

## Publish with GitHub Pages

1. Create a **public** repository named `hibbullah-landing` under `icrmahin`.
2. Push these files to its `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, then choose `main` and `/ (root)`.

The expected Pages address is `https://icrmahin.github.io/hibbullah-landing/` after GitHub Pages is enabled and the first deployment completes.

No build command is required. The site is static and the repository root is the publish directory.

## Brand reference

The page follows Hibbullah's existing app design contract: `#06402B` brand green, `#F6F7F4` paper surface, `#FFFFFF` card surface, Sora display typography, and Plus Jakarta Sans for supporting text. The logo is loaded from the public Hibbullah application repository.
